# Identidade visual — Campanha RPG

- `emblema-campanha-rpg.svg`: arquivo mestre vetorial. Atualize este arquivo para trocar o emblema.
- `favicon.ico`: fallback para navegadores e ambientes legados.
- `apple-touch-icon.png`: ícone de tela inicial para dispositivos Apple.
- `android-chrome-192x192.png` e `android-chrome-512x512.png`: ícones rasterizados de compatibilidade para instalação/PWA.

Os arquivos rasterizados foram gerados diretamente do SVG mestre, mantendo proporção e transparência.
