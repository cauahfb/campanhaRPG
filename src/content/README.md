# Conteúdo

Os diretórios desta pasta reservam espaço para as coleções editoriais planejadas. Na próxima etapa, cada coleção será declarada com Astro Content Collections e schemas Zod em `src/content.config.ts`.

Use Markdown (`.md`) com Frontmatter para regras, criaturas, termos, mecânicas, documentos e crônicas. Não publique informações que os personagens ainda não descobriram quando houver risco de spoiler.
